# 🐤 Flappy Bird Light (Pygame)

Un clone minimaliste et épuré du célèbre **Flappy Bird** réalisé en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 🎮 **Contrôle à une touche :** Appuie sur `ESPACE` pour faire voler l'oiseau.
- 🧱 **Obstacles dynamiques :** Génération aléatoire des hauteurs de tuyaux.
- 📈 **Score & High Score :** Compteur de score en direct et conservation du meilleur score.
- 🔄 **Redémarrage instantané :** Une touche pour rejouer.

---

## 🚀 Lancement

```bash
pip install pygame
python main.py
